# Pilotage – page d'accès

Page d'accès de l'application « Pilotage » (Google Apps Script) : icône, nom et ouverture plein écran sur l'écran d'accueil du téléphone.

- Le code d'accès est demandé une seule fois par appareil et conservé localement.
- Pour le ressaisir : ouvrir la page avec `#reset` à la fin de l'adresse.
